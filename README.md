# Wedding Decor Studio — Multimodal AI Venue & Pinterest Synthesis

An interactive AI wedding decor studio that combines an empty venue photograph with Pinterest-style inspiration references to preview complete wedding setups, 5-color palettes, spatial zone specifications, and an itemized vendor Bill of Quantities (BOQ).

## Local Development

```sh
npm install
npm run dev
```

## Tech Stack

- TanStack Start & React 19
- TypeScript & Tailwind CSS
- Google GenAI SDK (`@google/genai`) with Server-Side $1.00 USD Rate Limiter
